# tobysinclair.com

Personal site for Toby Sinclair, rebuilt from the Wix site as a Next.js app. Posts and landing pages live in `content/` as markdown so they stay editable.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Existing URLs from Google (`/post/...`, `/blog`, `/book-summaries`, category pages) are preserved.
